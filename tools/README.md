## 한 묶음 채우는 법

Claude에게 이렇게 말하면 된다. (구독 안에서 처리되니 따로 돈이 나가지 않는다)

> `tools/ko/ko01.json` 과 같은 형식으로, 다음 50낱말의 한국어 뜻풀이를 만들어줘.
> (여기에 `batches/batch02.txt` 내용을 붙여넣기)

한 묶음이 50낱말이고, 스무 묶음이면 1,000낱말이 찬다.
받은 결과를 `ko/ko02.json` 으로 저장하면 된다.

## 합치기

```
cd tools && python3 merge.py
```

`ko/` 안의 모든 파일을 모아 `../words.json` 을 새로 만든다.
앱은 이 파일을 읽어 낱말을 찾는다. 여기 있는 낱말은 **인터넷도 요금도 필요 없다.**

## 뜻풀이 형식

```json
"낱말": {
  "pron": "한글 근사 발음",
  "gram": "문법 정보 한 줄",
  "senses": [
    {"gloss": "한국어 뜻", "note": "쓰임 설명(없으면 생략)",
     "ex": [["러시아어 예문(강세 부호 포함)", "한국어 번역"]]}
  ],
  "idioms": [["관용구", "뜻"]],
  "etym": "어원 한 줄(없으면 생략)"
}
```

강세·변화형은 적을 필요가 없다. `merge.py` 가 OpenRussian 자료에서 자동으로 채운다.
